# 墨尔本 IMAX 电影票实时监控与智能抢票系统 (IMAX Melbourne Ticket Sniper)

这是一个专为**墨尔本 IMAX 影院（[web.imaxmelbourne.com.au](https://web.imaxmelbourne.com.au)）**打造的独立全功能抢票 Web 仪表盘，特别针对《THE ODYSSEY: IMAX 70MM PRESENTATION》（片号：HO00000547）及各类热门 IMAX 胶片重映场次设计。

---

## 🌟 核心特性与抢票规则

1. **一键显示所有电影余票**：
   - 实时拉取并展示当前墨尔本 IMAX 所有正在上映与预售的电影（70mm 胶片版、激光版、3D 版等）。
   - 直观展示放映场次、余票量进度条、剩余普通座位数。
2. **交互式全景座位图与一键选座**：
   - 真实比例还原墨尔本 IMAX 32m × 23m 巨幕影厅（A 到 U 排全景）。
   - **严格非残疾人座位**：自动剔除轮椅位（`Wheelchair`）与陪同位（`Companion`）。
   - **后排中间优选**：深度加权黄金后排（H、J、K、L、M、N、P、Q 排），根据距中心列的偏移量精准打分。
   - 支持**“一键推荐最佳后排中间座”**，智能选出最中央最舒适的观影席位。
3. **个人信息与付款凭证预填**：
   - 提前输入购票人姓名、邮箱、澳洲手机号及支付卡信息（保存在浏览器本地，安全隐私）。
   - 检出目标票时毫秒级自动填入订单，避免手动输错或延误。
4. **付款前自动给手机发送微信服务号提醒**：
   - 支持 **Pushplus 微信推送加**（免费、免复杂配置、微信服务号直接弹出模板卡片消息并响铃）。
   - 支持 **Server酱**（方糖微信服务号消息）。
   - 支持 **iPhone Bark / Telegram / Discord / Webhook**。
   - 锁票成功的瞬间，微信自动推送场次、已锁座位（如 Row M 18, Row M 19）、订单号以及 10 分钟锁票倒计时，手机点击直接进入官方付款页面！
5. **智能时间需求过滤**：
   - **周五、周六**：全天任意场次均监控。
   - **其余五天（周日至周四）**：仅监控晚上 18:00 及以后的黄金夜场。
6. **自动锁票与高分贝警报**：
   - 毫秒级锁定目标座位（官方系统临时保留 10-15 分钟）。
   - 网页触发 Web Audio 合成的高分贝警报音。
   - 弹出 10:00 倒计时锁票窗口，直接结算出票。

## 🚀 启动与运行方式

### 方式一：直接在浏览器打开（零依赖）
直接双击打开 `imax-sniper-web/index.html`，或者在终端执行：

```bash
# 进入目录
cd "imax-sniper-web"

# 使用任意本地静态服务打开，例如：
npx serve .
# 或使用 Python
python3 -m http.server 8080
```
在浏览器中访问 `http://localhost:8080` 或本地路径即可使用全部功能！

## 📲 微信服务号即时提醒配置指南 (30 秒完成)

系统支持在锁票瞬间向您的微信弹出提醒卡片：

### 推荐方式：Pushplus 微信推送加（免费免配置）
1. 用手机微信扫码或访问：[https://www.pushplus.plus](https://www.pushplus.plus)
2. 关注 **【pushplus推送加】** 微信公众号。
3. 登录后在页面顶部或个人中心复制您的 **个人 Token**（一串字符）。
4. 在抢票仪表盘点击右上角 **【📲 微信提醒配置】**。
5. 粘贴 Token，点击 **【📲 发送微信测试消息】**，手机微信将立即收到一条测试卡片！
6. 点击 **【保存配置】** 即可。

## 📋 完整五步抢票操作流程

1. **第一步：一键显示所有电影余票**
   - 点击界面顶部的 **【⚡ 一键显示所有电影余票】**。
   - 选择目标电影《THE ODYSSEY: IMAX 70MM PRESENTATION》，查看各日期（重点关注周五、周六及平日18:00后）的余票情况。
2. **第二步：输入个人信息与付款信息**
   - 在左下角表单中输入您的名、姓、接收电子票的邮箱、手机号（亦可点击“一键填入演示数据”）。
   - 输入付款信用卡信息。
   - 选择票种（成人/优惠等）及张数（如 2 张连座）。
3. **第三步：核对抢票需求规则**
   - 系统默认已勾选：
     - ☑️ 周五周六全天 或 其余五天 18:00 以后
     - ☑️ 严格排除轮椅及陪同座
     - ☑️ 后排优先 & 中间优先
4. **第四步：启动自动抢票监控**
   - 选择轮询频率（推荐 3 秒或 5 秒）。
   - 点击 **【🚀 启动自动抢票监控】**。
   - 控制台将进入实时扫描状态，并在有退票或新场次放出时毫秒级捕获。
   - （也可以点击 **【🧪 模拟检出退票并自动锁票】**，一键演练全流程效果）。
5. **第五步：自动填表锁票 ＋ 微信提醒 ＋ 10分钟完成付款**
   - 系统捕获到最佳后排中间座位后，自动完成锁票并保留 10 分钟。
   - 您的手机微信立即收到响铃提醒。
   - 网页播放警报并弹出结算窗口，点击 **【立即完成支付并出票】** 或官方直达通道即可顺利拿下！
